# 《搜打撤》完整策划案

> **一句话定位**：**肉鸽 × 自动战斗 × 搜打撤** 的 2D 像素俯视射击（单机 PvE / 安卓）。
> 进图搜索 → 遇敌交火 → 带着战利品跑到撤离点；死了就掉光身上的东西。
> 每局地图结构随机、规则变体随机，局局不重样。
>
> **本文件的性质**：**写在真实代码上的策划案，不是凭空设计**。
> 所有数值都来自 `data/*.json` 与 `sim/` 的实际实现，可用
> `godot --headless --path . --script res://tools/balance_report.gd` 复算。
> 已经落地的功能标 ✅，只是设计还没做的标 ⏳。
>
> 关联：`specs/roadmap-bac.md`（B→A→C 路线）· `data/SCHEMA.md`（数据契约）·
> `specs/art-pipeline.md`（美术）· `specs/tech-stack.md`（技术选型）。

## 0. 电梯陈述（30 秒版）

你是一名在废弃战区讨生活的拾荒者。**每一局都是一次赌注**：

- **搜**：翻箱子、摸尸体，背包只有 12 格 20 公斤，装什么全靠取舍；
- **打**：遭遇武装分子与感染体，可以手动刚枪，也可以**一键交给自动战斗**；
- **撤**：5 分钟倒计时，跑到撤离点待够 5 秒才算真的活着回来。

**死了，身上的装备和这一局搜到的东西全掉光**——这是全部紧张感的来源。
活着回来，东西进仓库，卖钱升级藏身处，下一局带更好的枪进去。

## 3. 玩法机制

### 3.1 战斗与弹道 ✅

- **射击**：`WeaponState` 管弹匣/射速/装填/后坐力；`LaneShotManager` 做开火节流。
- **命中判定**：`DamageModel.accuracy_at()` —— `距离衰减 × 散布惩罚`：
  - `falloff = 1 - clamp(距离 / 射程)`
  - `spread_penalty = clamp(1 - 散布/12, 0.05, 1)`
- **部位**：头 **×2.0** / 躯干 **×1.0** / 四肢 **×0.7**；命中率越高，爆头概率越高（4%→34%）。
- **距离衰减下限**：**0.40**（超出射程也能磨血，避免"完全打不动"的挫败）。
- **辅助瞄准** ✅：`AutoAim` 锁定 + 1.2 秒宽限期（`LOCK_GRACE`），
  判定半径来自 `AimAssist.DEFAULT_HIT_RADIUS`，**射程/散布词条会真正改变辅助瞄准的表现**
  （`build_loadout → to_weapon_def → WeaponState.def`）。
- **弹药弹型** ✅：标准 / 穿甲(AP) / 肉伤(HP)。对护甲目标
  `穿甲系数 = 0.25 + 0.75 × clamp(pen/护甲)`，无甲目标恒 1.0 —— **AP 打有甲、HP 打无甲**。

### 3.2 伤害、护甲与医疗 ✅

- **护甲吸收**：伤害的 **55%** 由护甲承担（`ARMOR_ABSORB`）。
- **流血**：轻 0.35 dps / 重 1.2 dps，持续掉血，需要止血带。
- **治疗**：`MedicalSystem` 有读条，**治疗中被打伤害 ×1.15** 且会打断 —— 逼你先找掩体。
- **负重**：超重减速，且影响机动。

### 3.3 敌人 AI ✅

- **感知**：`Perception`（视锥 = 视野距离 + 视角角度）+ `HearingFieldCache`（听声）。
- **状态机**：`EnemyAgent`（巡逻 / 警戒 / 交战 / 放弃），`give_up_dist_m` 控制脱战。
- **小队**：`Squad` 聚合警戒度，一人发现会扩散给同队（`反应时间 reaction_time` 分档）。
- **寻路**：`FlowFieldManager` 流场寻路（缓存命中率实测 100%）。

### 3.4 自动战斗（三个要素之一）✅

`sim/ai/player_autopilot.gd` 三态机：**IDLE → LOOT（搜）→ COMBAT（打）**。

| 参数 | 值 | 含义 |
|---|---|---|
| `STANDOFF_MIN/MAX` | 3.0 / 8.0 m | 交火时保持的站位距离 |
| `ENGAGE_MAX` | 16.0 m | 超过这个距离不主动接战 |
| `LOOT_ARRIVE` | 1.0 m | 到达容器判定距离 |
| `STUCK_TIMEOUT` | 2.2 s | 卡住判定（位移 < 0.08 就计入） |
| `BLACKLIST_SEC` | 8.0 s | 去不了的容器暂时拉黑 |

**新增（2026-10-16）**：搜刮完会自动评估背包里**品质更高**的同类装备并换上
（`Equipment.best_upgrade_slot()`，只升不降、无品质系统的老档不参与）。

### 3.5 搜刮 ✅

- 容器 8 类（木箱 / 补给箱 / 枪架 / 弹药箱 / 药柜 / 储物柜 / 货运箱 / 实验柜），
  容量 10~20，**搜索耗时 1.5~2.5 秒**（读条，这段时间你是有风险的）。
- 敌人死亡留**尸体**，可二次搜刮。
- 取物是**格位级**的：背包塞不下时，**带品质的装备留在原处**（不会静默丢失）。

### 3.6 装备系统（全境封锁 2 化）✅ Phase 1

- **4 个槽**：武器 / 护甲 / 头盔 / 背包。武器还有配件（跟枪走）。
- **5 档品质**：普通 → 精良 → 稀有 → 史诗 → 传说。

| 品质 | 词条数 | 强度 | 评分 | 死亡保留权重 | 掉落占比 |
|---|---|---|---|---|---|
| 普通 | 0 | 0.90 | 0.50 | 0.70 | **55.0%** |
| 精良 | 1 | 1.00 | 0.75 | 1.00 | **28.0%** |
| 稀有 | 2 | 1.10 | 1.00 | 1.50 | **12.0%** |
| 史诗 | 3 | 1.22 | 1.30 | 2.20 | **4.0%** |
| 传说 | 4 | 1.35 | 1.70 | 3.20 | **1.0%** |

- **8 个词条**（武器 5 / 护甲·背包 3）：

| 词条 | 字段 | 类型 | 范围 |
|---|---|---|---|
| 武器伤害 | damage | 正加成 | +4% ~ +12% |
| 射速 | rpm | 正加成 | +3% ~ +8% |
| 装填速度 | reload_time | 反向（越小越好） | -5% ~ -14% |
| 散布控制 | spread_deg | 反向 | -6% ~ -16% |
| 有效射程 | range_m | 正加成 | +5% ~ +12% |
| 护甲强化 | armor | 固定值 | +1 ~ +3 |
| 生命上限 | hp | 正加成 | +4% ~ +10% |
| 移动速度 | move_speed | 正加成 | +2% ~ +6% |

- **单一真源**：`GearGen.apply_affixes()` 是**玩家侧与敌人侧共用**的同一条数学。
- 武器词条烘进 `Loadout.effective` → `to_weapon_def()` → 真正改变战斗数值与辅助瞄准。
- ⏳ **Phase 2 候选**（未做）：品牌套装 / 天赋（条件触发词条）/ 校准重铸。

### 3.7 死亡与保留（痛感来源）✅

- 死亡 **掉光携带物 + 身上装备**（`DeathPolicy`）。
- **品质加权保留**：保留权重 = 物品价值 × `rarity.death_weight`
  （传说 3.2 / 史诗 2.2 / 稀有 1.5 / 精良 1.0 / 普通 0.7）。
  → 越好的东西越"值得抢救"，这是全境2味儿的痛感设计。
- 🔴 **门 1 未过**："死亡痛感"与"难度平衡"两个缺口**仍需人参与判断**。

### 3.8 藏身处（元循环）✅

| 系统 | 内容 |
|---|---|
| 仓库 | 基础 **64 槽**（可升级 +8/级，5 级） |
| 商人 | 卖出价 = 物品 value × **55%**（"商人关系"升级 +6%/级，3 级） |
| 制造 | **12 个配方**，4 个工作台（lab / bench / kitchen / …） |
| 升级 | 仓库扩建 / 负重训练(+3kg/级) / 战地急救(治疗 +12%/级) / 商人关系 |
| 任务 | **4 个**（初战告捷 / 全身而退 / 拾荒者 / 猎手），奖励钱包 + 物品 |
| 配装 | `Hideout.loadout` 跨局持久，战局引用共享 —— **死亡连身上装备一起丢** |

### 3.9 肉鸽（三个要素之一）✅ Phase 1

两层随机：
1. **结构随机**：BSP 切分（最多 2^5=32 叶）+ MST 保证连通 + **15% 加环**
   （`CYCLE_RATIO`）—— 有环才有"绕路"和"被包抄"的战术空间。
2. **规则随机**：每局 roll **1~2 个局内变体**，同组互斥：

| 变体 | 组 | 效果 |
|---|---|---|
| 敌潮 | enemy | 敌人密度 **×1.35** |
| 防线薄弱 | enemy | 敌人密度 **×0.75** |
| 富饶容器 | loot | 容器搜索次数 **×1.4** |
| 被搜刮过 | loot | 容器搜索次数 **×0.7** |

HUD 会显示"本局变体"一行。
⏳ **Phase 2 候选**（未做）：撤离时间变体 / 敌人类型权重偏移 / meta 成长。

## 9. 设计红线（改动时必须守住）

1. 🚫 不申请网络权限，代码内零网络请求。
2. 🚫 零变现：无内购 / 无广告 / 无打赏。
3. 🚫 禁止从商业游戏提取素材；付费素材不入仓库。

5. ⚠️ 所有随机走 `SimRng` **注入**，同 seed 必须可复现（T-32）。
6. ⚠️ 数据以 `data/*.json` 为**唯一真源**，改数值改 JSON，不改代码里的魔数。
7. ⚠️ 倍率/权重若未经平衡专家确认，**一律标注"待定夺"**，不自作主张定难度。
