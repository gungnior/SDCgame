`aspect = expand`、`scale_mode = integer`。**所有 UI 设计稿请按 640×360 出**，
不要按手机物理分辨率设计——引擎会整数倍放大，非整数倍会糊。

## 3. 交互模型（UI 策划要顺着它设计）

### 3.1 战局触屏（`ui/touch_controls.gd`）

```
 ⚙菜单(左上)        ← toast 区 →        ▦地图(右上)
 ┌──────────────────┐  ┌──────────────────────────┐
 │                  │  │                          │
 │   移动摇杆        │  │      瞄准摇杆（FIXED）      │
 │  DYNAMIC 浮动     │  │      始终可见             │
 │  （按下才显示，    │  │                          │
 │    避免幽灵摇杆）  │  │    ⟳换弹   ✚治疗   ◌静步   │
 │                  │  │                          │
 │                  │  │    ▤背包                  │
 │                  │  │                          │
 │                  │  │         ◉ 开火            │
 └──────────────────┘  └──────────────────────────┘
```

- **双摇杆分离**：左移右瞄。移动用 DYNAMIC（浮动、按下才显示），
  瞄准用 FIXED（固定锚点、始终可见）—— 瞄准少一次"找零位"延迟，是刻意设计
- **开火键**：尺寸最大；`use_hold = true`（按住连发）。另有 `auto_fire` 开关变量已预留
- **静步**：移速 ×0.55、噪音大幅降低（替代"蹲伏"）
- **键位是用户逐次反馈调出来的**：齿轮在左上（用户明确要求）、地图在右上（全屏唯一空位）、
  静步插在治疗与背包之间的空档 —— **调整前先看 §4，这些位置都有理由**
- **拖拽**：所有物品行的第二交互方式（第八轮 #4），点击仍是第一交互

## 6. 🔒 技术约束（动手前必读，违反会直接破）

这些是这个项目**用真机 bug 换来的教训**，改 UI 时务必遵守：

1. **面板必须自绘视口**：挂在 `CanvasLayer` 下的 `Control` 没有 Control 父节点，
   锚定会解析失败 → 必须在 `_fit_viewport()` 里显式
   `position = Vector2.ZERO; size = vp; set_anchors_preset(FULL_RECT)`。
   （只设锚定会得到 0×0 面板——这个 bug 出过两次。）
2. **长提示文本必须 `clip_text = true`**：长 `Label` 会撑爆父容器最小宽度，
   把关闭按钮顶出屏幕。（三个面板各栽过一次。）
3. **宽按钮判定**：`TouchButton` 只在 `size.x > size.y * 1.4` 时画圆角矩形，
   否则退化成圆形 → `−` `+` 这类单字符会渲染成圆点。按钮别做成接近正方形。
4. **面板幂等**：测试环境 `root.add_child(x)` **不会触发 `_ready`**，
   所以 `_ready()` 和 `open()` 都要调 `_ensure_built()`。
5. **清空子节点用 `remove_child` + `queue_free`**：直接 `queue_free` 是延迟释放，
   headless 测试里子节点计数会累加，导致断言失败。
6. **资源文件规矩**：`.tscn` 不能有注释；不手写 UID；一律 `format=3`。
7. **视口 640×360**：设计稿按这个出，见 §1。

### 令牌系统用法（UI 策划必读）

`ui/tokens.gd` 分六组，**新增颜色请加令牌，不要在业务代码里写 `Color(...)`**：

| 组 | 令牌 | 用途 |
|---|---|---|
| 三层底色 | `BG_DEEP` / `BG_PANEL` / `BG_CARD` / `BG_RAISED` | elevation 层次 |
| 边框 | `BORDER` / `BORDER_HI` | 卡片描边、浮层亮边 |
| 四档文字 | `TEXT_HI` / `TEXT` / `TEXT_MID` / `TEXT_LOW` | 亮度即层级 |
| 强调与功能 | `ACCENT`(琥珀金·主) / `DANGER` / `SUCCESS` / `INFO` / `RARE` / `STEALTH` / `NEUTRAL` | **只表达语义，不拿来"好看"** |
| 字号阶梯 | `FS_DISPLAY 28` / `FS_TITLE 20` / `FS_HEAD 16` / `FS_BODY 13` / `FS_CAPTION 11` | 640×360 逻辑像素 |
| 间距/圆角 | `SP_1~SP_6`(4 的倍数) / `R_SM R_MD R_LG` | 对齐像素栅格 |

助手函数：`panel_box()` / `card_box()` / `raised_box()` / `accent_box()` 返回 `StyleBoxFlat`；
`fade(color, alpha)` 做透明度派生。

> ⚠️ **两个 GDScript 陷阱**（本项目已踩过，改令牌时别复犯）：
> ① `@export var x := UITokens.XXX` **非法**——@export 默认值不能引用跨类 const，要写字面量；
> ② `const X := UITokens.fade(...)` **非法**——const 只接受常量表达式，跨类 const/静态函数都不行，要用 `var`。
